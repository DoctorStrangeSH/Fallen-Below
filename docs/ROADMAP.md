# ABYSSAL GENESIS — дорожная карта

**Версия 0.1** · 27 ноября 2026

Этапы следуют дорожной карте мастер-брифа (14 этапов). Что строим — `docs/GDD.md`; как — `docs/TECH_SPEC.md`; сюжет — `docs/NARRATIVE_BIBLE.md`.

**Правила:**
1. Этап закрывается только после приёмки (тесты, бот, скриншоты, где нужно — плейтест).
2. Статусы: DONE / PARTIAL / NOT DONE / BLOCKED.
3. **Массовый сюжетный контент не пишется до завершения вертикального среза (этап 11).** До этого — только 5 сцен среза (Narrative Bible 22.1).
4. После среза — решение владельца: расширять или чинить ядро (бриф, раздел 23).
5. Существующие системы Fallen Below не удаляются без согласия владельца.

## Порядок производства сюжета (этап 12)

1. Акт I полностью (2 биома, 2 босса, Z1/E1/E2).
2. Акт II (выбор порядка биомов, A1, V1, Ивара, Хранитель-7).
3. Акт III (Z2, V2, A2, E3, Ваэль, признание Архонта).
4. Акт IV (A3, Z3, V3, Хор, колыбельная).
5. Акт V, 6 концовок, эпилог «Корень».
6. После кампании: Книга исходов, послесловия, Комната Лии, стадии меню.
7. Echoes of Genesis (этап 13).

После каждого акта: `tools/narrative_check.py` и unit-тест EndingEvaluator.
