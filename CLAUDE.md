# Fallen Below — notes for Claude

- Engine: Godot 4.7, GDScript, GL Compatibility renderer, 1280x720 canvas_items stretch.
- **Transition in progress to ABYSSAL GENESIS**: master brief `docs/ABYSSAL_GENESIS_BRIEF.txt`, audit and migration plan `docs/AUDIT_ABYSSAL_GENESIS.md` (stage 01 done; owner decisions in section 9a), story source of truth for the new game `docs/NARRATIVE_BIBLE.md` (supersedes `docs/STORY.md`, which stays as the Fallen Below archive). Do not delete or rewrite existing systems without the owner's agreement; the pre-transition version is commit `1c4cbc2` (local tag `fallen-below-v0.4`; pushing tags is denied from this sandbox).
- Design source of truth: `docs/GDD.md` (Russian). Update its checklist (section 10) when features land.
- Talk to the owner in Russian. Source strings in code are English; every player-facing string goes through `Loc.t("English text")` (autoload `Loc`, `scripts/autoload/loc.gd`). Russian lives in `tools/ru_strings.py` → `python3 tools/build_locale.py <godot>` writes `locale/ru.json` and lists missing keys. Data strings (names/descs/story) are translated at display time with `Loc.t(D.X[...]["name"])`. Keep `%s/%d` placeholders identical. When exporting, include `*.json` as non-resource files.
- Architecture: `run.gd` (root, clock, input) owns `RunState` (RefCounted, all run data + queries) and system Nodes in `scripts/systems/` that get `run` and `s` injected. View (`run_view.gd`) and HUD (`run_hud.gd`) only read state and call run/system methods. All data/balance in `scripts/data/game_data.gd`. Meta progression + save in autoload `Meta`.
- Use `const X = preload(...)` instead of `class_name` to avoid global-class cache issues. Systems must not preload `run.gd` (cycle); keep `var run` untyped.
- Planning: `RunState.time_stopped()` (paused, blocked, or auto-pause while `selected >= 0`/`holding`); `is_blocked()` no longer includes pause, so the player acts while paused. Esc opens `scripts/ui/settings_panel.gd`. Drag & drop in `run_hud.gd` (`_begin/_input/_start_drag`). Lures: `D.LURE_LEVELS`, `s.lure_level`, `s.forecast` via `hero_system.roll_forecast()` (seeded; spawn_party uses it), `Meta.lure_cost()`, building `bait_workshop`. Tests: `tests/ui_test.tscn`, `tests/story_test.tscn`; bot `--loud=0..2`.
- Run HUD layout: top bar (time/attention/controls), right Warden sheet + dungeon levers, hand at bottom; icons from `scripts/ui/icons.gd` (`Icon.make(kind, size)` control in `scripts/ui/icon.gd`); hover text via `hud._hint(control, callable)`. Bot `--hover=x,y` for tooltip screenshots.
- Menus: `UI.background` (animated `backdrop.gd`), `UI.title`, `UI.primary`, `UI.frame`, `UI.hover_tip(self).bind(control, callable)`. Heart drawn by `Icons.heart()` (map, menu, Lair den).
- Sprites: `scripts/ui/art.gd` loads `res://art/<id>.png` if present, otherwise views draw primitives. Asset ids and prompts: `docs/ART.md`.
- Concept (GDD v0.3 "Hungry Dungeon"): the dungeon lures travelers below; the player builds halls and the **Warden** (player's monster, `warden_system.gd`, data in `RunState.warden`) patrols the loop backwards and fights. Warden death ends the run. Travelers escape after 3 laps (raises the Order's attention -> champion). Lures pick traveler types; souls stance devour/raise. Internally travelers are still called "heroes". All 4 acts playable; Act IV Night/Nightfall (`s.night`, `s.nightfall`, `run.nightfall()`, key N / click heart), Archon sunbursts + `s.sanctified`; endings in `scenes/ending.tscn` (`ending_*` stories, true ending needs the full Book). Acts: (`D.ACTS` with per-act `"cards"`, `Meta.selected_act`/`max_act()`, lures/classes with an `"act"` key exist only in that act; Brann's charges and Vael's ignitions in `hero_system.boss_tick`; Act III fire in `fire_system.gd` (`s.fires`, click quenches for Blood); bot `--act=N`, `--noquench=1`, `--shot_night=1`). Story bible: `docs/STORY.md`. In-game story text lives in `game_data.gd` (STORY, BEATS, BOSS_LINES, FRAGMENTS, MEMORIES, WHISPERS, ACTS); one-time beats via `run.beat(id)` + `Meta.first_time`; narration via `RunState.narrate` signal; `scenes/story.tscn` plays pages via `Meta.play_story()`.
- Map is procedurally generated each run in `run_state.gd` (`_random_region` → `_trace_ring` → `_commit_loop` + detours).
- Design rule from the owner: no mechanics for the sake of mechanics. Every feature must create a visible player decision tied to the core loop.
- Music: autoload `Music` (`scripts/autoload/music.gd`): `play("menu"|"story"|"run"|"boss")`, `set_intensity()`, `stinger()`. Tracks generated by `tools/music_gen.py` (v2: leitmotif, synthesized ensemble, convolution reverb, seamless loops; `python3 tools/music_gen.py [track]`) into `audio/music/`; `tools/sfx_gen.py` uses `tools/synth_basics.py`. Warden XP/abilities: `D.ABILITIES[warden_id]`, gated by the `pit` building (`Meta.growth_unlocked()`).
- Feedback: `RunState.fx(kind, target, amount)` signal → `run._on_fx` plays `Sfx` (autoload, `audio/sfx/*.ogg` from `tools/sfx_gen.py`) and `run_view.add_fx` (floating numbers, bursts). Emit fx for any new visible event.
- Balance model: `tools/balance_sim.py` (Python, mirrors key numbers from game_data.gd; keep in sync when tuning). Debug keys F1–F5 in `run.gd` (debug builds only).
- Godot can be run in this sandbox: download `Godot_v4.7.1-stable_linux.x86_64.zip` from GitHub releases, `--headless --import`, then `--headless res://tests/bot.tscn -- --runs=N --warden=.. --lure=..` (autoplay bot, prints win/death stats; Meta.no_save). Screenshots: `xvfb-run -a -s "-screen 0 1280x720x24" godot --rendering-driver opengl3 res://tests/bot.tscn -- --runs=1 --shot=/path.png --shot_day=7`. Always run the bot after gameplay changes. Note: `--check-only --script` falsely reports "Meta not found"; run scenes instead.
- GDScript gotcha: don't use `:=` on values read from Dictionaries (Variant) — declare explicit types.
