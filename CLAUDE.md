# Fallen Below — notes for Claude

- Engine: Godot 4.7, GDScript, GL Compatibility renderer, 1280x720 canvas_items stretch.
- Design source of truth: `docs/GDD.md` (Russian). Update its checklist (section 10) when features land.
- Talk to the owner in Russian. In-game text is English for now (Steam audience); localization via `tr()` later.
- Architecture: `run.gd` (root, clock, input) owns `RunState` (RefCounted, all run data + queries) and system Nodes in `scripts/systems/` that get `run` and `s` injected. View (`run_view.gd`) and HUD (`run_hud.gd`) only read state and call run/system methods. All data/balance in `scripts/data/game_data.gd`. Meta progression + save in autoload `Meta`.
- Use `const X = preload(...)` instead of `class_name` to avoid global-class cache issues. Systems must not preload `run.gd` (cycle); keep `var run` untyped.
- Sprites: `scripts/ui/art.gd` loads `res://art/<id>.png` if present, otherwise views draw primitives. Asset ids and prompts: `docs/ART.md`.
- Concept (GDD v0.3 "Hungry Dungeon"): the dungeon lures travelers below; the player builds halls and the **Warden** (player's monster, `warden_system.gd`, data in `RunState.warden`) patrols the loop backwards and fights. Warden death ends the run. Travelers escape after 3 laps (raises the Order's attention -> champion). Lures pick traveler types; souls stance devour/raise. Internally travelers are still called "heroes". 4 acts planned. Only Act I is playable. Story bible: `docs/STORY.md`. In-game story text lives in `game_data.gd` (STORY, BEATS, BOSS_LINES, FRAGMENTS, MEMORIES, WHISPERS, ACTS); one-time beats via `run.beat(id)` + `Meta.first_time`; narration via `RunState.narrate` signal; `scenes/story.tscn` plays pages via `Meta.play_story()`.
- Map is procedurally generated each run in `run_state.gd` (`_random_region` → `_trace_ring` → `_commit_loop` + detours).
- Design rule from the owner: no mechanics for the sake of mechanics. Every feature must create a visible player decision tied to the core loop.
- Balance model: `tools/balance_sim.py` (Python, mirrors key numbers from game_data.gd; keep in sync when tuning). Debug keys F1–F5 in `run.gd` (debug builds only).
- Godot can be run in this sandbox: download `Godot_v4.7.1-stable_linux.x86_64.zip` from GitHub releases, `--headless --import`, then `--headless res://tests/bot.tscn -- --runs=N --warden=.. --lure=..` (autoplay bot, prints win/death stats; Meta.no_save). Screenshots: `xvfb-run -a -s "-screen 0 1280x720x24" godot --rendering-driver opengl3 res://tests/bot.tscn -- --runs=1 --shot=/path.png --shot_day=7`. Always run the bot after gameplay changes. Note: `--check-only --script` falsely reports "Meta not found"; run scenes instead.
- GDScript gotcha: don't use `:=` on values read from Dictionaries (Variant) — declare explicit types.
