# Fallen Below

*Loop Hero in reverse: build the dungeon, kill the heroes, raise them as your army. Only the dead remember who they were.*

Roguelite с непрямым управлением на **Godot 4.7**. Полный дизайн: [docs/GDD.md](docs/GDD.md).

## Как запустить

1. Скачай Godot 4.7: https://godotengine.org/download (обычная версия, не .NET).
2. Запусти Godot → **Import** → выбери `project.godot` из этой папки.
3. Нажми **F5** (Run Project).

## Как играть

Ты Сердце Бездны. Герои Ордена Рассвета спускаются, чтобы добить тебя. Loop Hero наоборот.

- **Кольцо каждый раз новое.** Герои входят через **GATE** и идут по кругу. Каждый круг — кража из Сердца, укравший 3 раза сбегает.
- **Каждый день** выбираешь 1 карту-воспоминание из 3. За убийства дают ещё карты.
- Нажми карту внизу, потом клетку: **залы и ловушки** кладутся на тропу, **алтари и кладбища** рядом с ней.
- **Развилки** (жёлтые точки): герои выбирают ветку по характеру. Жадных манит Cursed Chest, паладинов тянет к алтарям и нежити, трусы обходят опасность.
- **Души:** поднять (нежить встаёт на месте смерти и шепчет правду об Ордене), поглотить (эссенция) или допросить (карты).
- **Трофеи** справа: нажми трофей, потом свою нежить, чтобы надеть. ПКМ переплавляет трофей в эссенцию.
- **Внимание Ордена** растёт от твоих карт и убийств. На 100% приходит **Аурелия**: её сияние жжёт нежить рядом, поэтому прикрой её путь живыми монстрами и ловушками.
- **Seal** завершает забег: 100% костей каждый 5-й день, 60% в другие. Если Сердце пало, только 30%.
- **Секретные комбо** записываются в Гримуар.
- Наведи мышь на тайл, чтобы увидеть, кто там. Пробел ставит паузу, 1/2/3 меняют скорость, ПКМ отменяет выбор.

## Меню и Логово

- Игра стартует с главного меню: **New Run**, **The Lair**, **Quit**.
- В конце забега ты получаешь **Bones** (дни × 3 + убийства, +25 за победу).
- В **Логове** Bones тратятся на постройки: больше HP Сердца, стартовые склянки, карты, эссенция и открытие карты Graveyard.
- Прогресс сохраняется в `user://save.json`. На Windows это `%APPDATA%\Godot\app_userdata\Fallen Below\`.

## Структура

```
docs/GDD.md                  дизайн-документ
scenes/                      main_menu, lair, run
scripts/autoload/meta.gd     мета-прогресс и сохранения (autoload "Meta")
scripts/data/game_data.gd    все данные и баланс: карты, герои, черты, постройки
scripts/run/run.gd           корень забега: часы, ввод, связывает системы
scripts/run/run_state.gd     состояние забега + запросы
scripts/run/run_view.gd      отрисовка карты (пока примитивы)
scripts/run/run_hud.gd       интерфейс забега
scripts/systems/             hero / combat / card / soul / loot системы
scripts/menu/                главное меню, Логово, Гримуар, сюжетные сцены
scripts/ui/ui_style.gd       общие стили UI
```

Баланс правится в одном месте: `scripts/data/game_data.gd`.
